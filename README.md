💰 Hệ thống Quản lý các phòng ban trong công ty

Đây là một dự án Full-Stack Web Application đơn giản dành cho việc quản lý các phòng ban trong công ty.

Chức năng chính

Xem, thêm, sửa, xóa các phòng ban

Thông tin tài khoản: Hiển thị thông tin cá nhân, thay đổi thông tin cá nhân và mật khẩu

🛠️ Công nghệ sử dụng

Backend: Java, Spring Boot

Frontend: ReactJS, Redux

Database: MySQL

🚀 Cách cài đặt & chạy dự án

Yêu cầu

Spring Tool Suite / IntelliJ / Eclipse (có hỗ trợ Spring)

Visual Studio Code

Các bước thực hiện

Khởi động Database

Mở MySQL WorkBench và chạy file `GroupManagementDatabase.sql`

Khởi động Backend 

Mở project backend bằng Spring Tool Suite

Run project để khởi động server

Khởi động Frontend

Mở project frontend bằng VSCode

Chạy 'npm install' trong terminal

Chạy 'npm install react-router-dom react-redux @reduxjs/toolkit axios react-hook-form @hookform/resolvers yup lucide-react'

Chạy 'npm run dev' và truy cập tại http://localhost:5173/login
